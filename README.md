# 课页 · 个人课件资料库

课页（KEYE）将华工视频平台课件获取、本地资料管理、页面筛选和 PDF 导出连成一个工作流程。课程封面由代码自动生成，无需平台提供封面；课件预览使用真实页面。

## 启动

双击项目中的 `启动课页.cmd`，或在项目目录执行：

```powershell
.\.venv\Scripts\python.exe app.py
```

`start.ps1` 也已切换到新版入口。旧版下载器保留在 `main.py`，设计原型保留在 `prototype/`，两者均不是新版启动入口。

## 第一次使用

1. 进入“获取课件”，连接平台并在学校网页完成登录；课页会自动识别登录状态并扫描日期范围。
2. 选择课程并获取。下载完成后，在“资料库”打开课件；勾选页面或选择范围，排除无效页。
3. 第一次快速导出时，系统才会询问默认 PDF 保存目录；选定后会立即继续导出并记住选择。
4. 后续快速导出直接使用这个目录。“另存为”仍可临时选择其他位置；默认目录只在“设置”中主动修改。

也可通过“导入文件”导入 PDF、图片或旧版下载目录：PDF 分别入库，选中的图片合成一份课件，目录按图片文件夹分组。同一课次同时存在图片和 PDF 时优先导入图片，避免重复。

## 页面整理

- 单击缩略图预览，双击放大。
- 勾选表示批量操作对象；“排除”表示不会导出，两者独立。
- 支持连续范围选择、批量排除、恢复、撤销、仅查看保留页。
- 方向键翻页，E 排除/恢复，Ctrl+Z 撤销。
- 筛选结果立即写入 SQLite，关闭后再开仍保留；撤销栈仅在当前整理会话有效。
- 导出使用提交时的页面快照。导出期间或之后继续修改，将显示“修改后未导出”。

## 数据与文件

```text
library/
  library.sqlite   课件、页面选择、任务与设置
  materials/       原始文件、页面预览、缩略图
  temporary/       失败或尚未完成下载，可重试复用
  exports/         旧版本曾使用的内置输出目录
```

- 原始文件保留，排除不删图。回收站仅修改记录，不删除已经导出的 PDF。
- 导入复制源文件，不移动源文件。已有 PDF 导出时直接保留所选原 PDF 页，不把预览图当作输出。
- 资料库使用相对文件路径，可在退出应用后整体备份、复制。设置中的“切换资料库”打开另一个目录，不自动搬迁。
- 新版启动时读取旧 `config.json` 的下载参数和导出目录，不继承“合成后删除原图”。新版设置保存在资料库中，资料库位置保存在 `app-settings.json`。
- 登录凭据只在本次进程内使用，不写入课件数据库，也不传给界面脚本。
- 部分图片下载失败时，不发布缺页课件；在任务页重试。程序异常退出的未完成任务，下次启动显示可重试状态。
- 自动导出使用不覆盖已有文件的名称；手动导出由系统文件对话框确认覆盖。
- 新安装没有预设导出目录，也不会在启动时打断用户。首次导出、批量快速导出或启用“获取后自动导出”时才会选择并保存目录；取消选择不会创建任务。

## 安装环境

本机使用独立 Python 3.13.2 和项目 `.venv`。重建：

```powershell
& "$env:LOCALAPPDATA\Programs\Python\Python313\python.exe" -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

主要依赖：PySide6（桌面、内置浏览器和界面通信）、requests、Pillow、pypdf、pypdfium2。

## 代码结构

- `app.py`：新版主窗口与启动入口。
- `web/`：沿用确认过的界面布局，使用真实数据，不含演示课程。
- `core/desktop.py`：界面通信、原生文件对话框、登录交接和后台任务。
- `core/library.py`：SQLite、原文件、预览生成、页面筛选和 PDF 导出。
- `core/downloader.py`：沿用平台课表及课件接口，支持并发下载与重试。
- `auth/browser_login.py`：学校登录浏览器。

### 课程与连续整理（2026-09-06）

- 资料库首页以课程为单位；课程内按上课日期列出各份课件，整理状态和导出状态独立显示。
- 扫描结果按平台课程分组，勾选课程可获取其尚未获取的课次，也能展开单独选择。
- 支持选择最近三份、按日期筛选、选择待整理课件，连续整理时记住范围和每份课件的页码。点击“标记已整理”才算完成；后续修改页面会重新进入整理中。
- 课程内支持备注、手动归类、学期 / 班级标签。在课程页面导入文件会直接归入该课程。
- 批量导出可分别保存到课程文件夹，或合并为带课次书签的 PDF。导出始终使用开始任务时保存的保留页面，不改变原始文件。分别导出取消后保留已完成文件，重试使用新文件名。
- 新平台课件按账号、平台课程标识归类，不按名称猜测。旧课件重新扫描匹配后可自动归类；尚未确认归属的旧课件与首页导入的本地资料进入“未归类”，可手动分配。
- 首次升级有资料的旧数据库会先备份为 `before-courses.sqlite`；页面文件、剔除记录、原导出记录保留。新结构增加课程表及整理范围记录。
- 15 项回归测试通过；本地完整界面联调覆盖 20 份课件、6 份待整理、仅连续处理最近 3 份，以及重载恢复、合并书签和按课程分别导出。联调使用临时资料，不写入用户资料库。

### 自动登录交接与扫描（2026-09-15）

- 学校网页登录完成后，课页自动检测完整登录状态、自动关闭登录窗口并按当前日期范围扫描课表，无需点击“导入登录态”。
- 修改开始日期或结束日期后会短暂等待并自动重新扫描，避免连续选择日期时发起重复请求。
- “立即重新扫描”按钮保留，用于主动强制刷新当前日期范围。

### 快速导出与打包（2026-09-20）

- 整理是可选步骤。单份课件和选中的多份课件都可直接快速导出，使用当前保留页面并保存到默认课程目录；无需先标记“已整理”。
- “另存为”用于自选文件名和路径，“更多导出方式”用于合并 PDF 或选择其他根目录。
- 获取页可启用“获取完成后自动导出 PDF”，下载完成即生成 PDF，同时仍保留原始页面。
- 目录版打包使用 `build.ps1`，输出为 `release/课页/Keye.exe`，并生成可直接分享的 `release/课页-Windows-x64.zip`。整个“课页”目录需要一起复制和运行。
- 学校网页登录和课件接口固定直连，不继承系统代理。学校 WAF 会把部分代理出口识别为校外并返回 403；校外使用时应先连接学校 SSLVPN。
- 编辑器支持 Shift 连选：先勾选一个页面，再按住 Shift 勾选另一页，可选中或取消两者之间的整段页面。
