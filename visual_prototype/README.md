# 课页视觉优化原型

这是从当前正式界面复制出的独立视觉原型。页面结构、课程分组和整理流程保持一致；资料全部在临时目录中生成，退出后自动删除，不会读取或修改正式资料库。

运行：

```powershell
.\.venv\Scripts\python.exe .\visual_prototype\preview.py
```

本轮重点检查：

- 正文、辅助信息和状态文字是否清楚；
- 主次按钮是否容易区分；
- 课程表格、课件缩略图和整理状态是否容易扫读；
- 1440×960 与 1000×760 窗口下是否存在溢出或重叠；
- 标题栏和 Windows 任务栏图标是否统一显示“课页”标识。

原型确认前，不会把这套样式和图标写入正式程序。
