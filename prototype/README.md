# GetPPTApp 交互原型

这一版用于确认资料库、获取课件、整理、任务、设置之间的布局与交互。
是独立原型，尚未改造真实下载程序；所有课件图片和课程均为示例。

## 打开

在项目根目录运行：

```powershell
.\.venv\Scripts\python.exe prototype\preview.py
```

也可以直接用浏览器打开 `prototype/index.html`。使用同一个浏览器和地址时，整理记录通过 localStorage 保留。清除浏览器数据或在设置中重置原型后，示例会恢复。

## 建议体验路径

1. 在资料库点击“继续整理”，通过缩略图勾选页面，或使用“选择范围”。
2. 批量排除、恢复、撤销，切换“仅保留页”。蓝绿色边框表示选中；灰色遮罩表示排除。
3. 双击缩略图打开大图；方向键翻页，E 排除或恢复，Ctrl+Z 撤销。
4. 点击“导出 PDF”并确认演示导出，前往任务页查看状态。
5. 再次修改已导出课件，观察“修改后未导出”状态；刷新后检查筛选是否保留。
6. 获取课件 → 连接平台 → 使用演示账号 → 扫描 → 获取选中课件。切换到其他页面，后台任务继续。
7. 试试暂停、继续、取消；完成后打开整理。
8. 导入示例 PDF；使用课件卡片右下角菜单移入回收站，再恢复。

## 范围

- 已可交互：导航、搜索、筛选、排序、缩略图、大图、范围选择、排除恢复、撤销、自动保存、演示任务、回收站、导入示例、导出状态、默认获取方式。
- 示例任务不访问学校平台，不读取真实文件，不生成 PDF。
- 正式版尚需接入：SQLite 资料库、原始素材、真实登录及下载、图片/PDF 导入、PDF 导出、异常恢复、迁移与备份。
- 原程序仍由项目根目录的 `main.py` 启动，真实配置和下载目录没有改动。

## 验证

```powershell
.\.venv\Scripts\python.exe prototype\verify.py
```

该检查使用 Qt 内置浏览器运行交互流程，并保存页面截图至 `prototype/review/`。需要操作系统允许 QtWebEngine 子进程正常运行。
